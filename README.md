# 자동 지오코더 v2.17

## 빌드 

`build_exe.cmd`를 더블클릭하면 Windows용 EXE를 생성합니다.

## 주요 기능

- `xlsx`, `xls`, `csv`, `tsv` 형식의 파일을 입력 파일로 사용할 수 있습니다.
- 파일 선택 창을 통해 사용자가 직접 입력 파일을 선택할 수 있습니다.
- 입력 데이터의 컬럼명을 자동으로 확인하여 `도로명주소`, `지번주소`가 포함된 컬럼을 탐지합니다.
- `시도`, `시군구`가 포함된 컬럼이 있으면 해당 값을 주소 보완에 자동으로 활용합니다.
- 입력 파일의 `시도`, `시군구` 값이 비어 있는 경우 프로그램 화면에 입력한 시도·시군구 값을 보조값으로 사용합니다.
- 도로명주소만 있는 경우 도로명주소를 이용해 좌표를 조회합니다.
- 지번주소만 있는 경우 지번주소를 이용해 좌표를 조회합니다.
- 도로명주소와 지번주소가 모두 있는 경우 두 주소를 각각 조회한 뒤 좌표 간 거리를 비교해 정합성을 검증합니다.
- 두 주소가 모두 조회된 경우 도로명주소 좌표를 우선 결과로 사용합니다.
- 도로명주소 조회에 실패하고 지번주소 조회에 성공한 경우 지번주소 좌표를 사용합니다.
- 검증 허용거리는 사용자가 직접 설정할 수 있으며 기본값은 1,000m입니다.
- 기본 좌표계는 `EPSG:4326`이며, 프로그램 화면에서 다른 좌표계로 변경할 수 있습니다.
- 결과 파일의 오른쪽 끝에 `X좌표`, `Y좌표`, `사용주소`, `검증여부` 컬럼을 추가합니다.
- 동일한 주소가 반복되는 경우 캐시를 활용하여 불필요한 API 재호출을 줄입니다.
- 작업 진행 상황을 Progress Bar와 하단 로그 창에서 실시간으로 확인할 수 있습니다.
- 로그 창에는 처리 행, 장소명, 성공·실패 현황, 저장 현황 등이 표시됩니다.
- `장소명` 컬럼이 있는 경우 로그에 최대 6글자까지 표시하며, 초과하는 경우 `...`으로 축약합니다.
- 100건 처리할 때마다 결과를 자동으로 중간 저장합니다.
- 전체 데이터가 100건 미만인 경우 작업 완료 시 한 번에 저장합니다.
- 작업 중 `중지` 버튼을 누르면 현재까지 처리한 결과를 저장합니다.
- 중지 후 동일한 입력·출력 파일로 다시 시작하면 이전 처리 위치를 확인하여 이어서 작업할 수 있습니다.
- 작업이 정상 완료되면 이어하기용 임시 복구 정보는 자동으로 삭제됩니다.
- 결과 저장 위치를 사용자가 직접 지정할 수 있습니다.
- 작업 완료 후 결과 폴더를 프로그램에서 바로 열 수 있습니다.
- VWorld 주소 API를 이용해 좌표를 조회합니다.
- 통신 오류가 발생하면 일정 횟수 자동 재시도합니다.
- SSL 인증서 검증 사용 여부를 설정할 수 있습니다.
- 빌드 폴더에 `icon.png`가 있으면 빌드 시 자동으로 `icon.ico`로 변환하여 프로그램 아이콘으로 적용할 수 있습니다.
- PyInstaller로 생성한 실행 파일은 Python이 설치되지 않은 Windows PC에서도 실행할 수 있습니다.

## config 파일 설정
- `api_key`: VWorld Geocoder API 2.0 API KEY
    - VWorld에서 발급받은 API 인증키를 입력합니다.
    - 주소를 좌표로 변환하기 위해 반드시 필요한 값입니다.
    - 발급 및 사용 방법: https://www.vworld.kr/dev/v4dv_geocoderguide2_s001.do
- `ssl_verify`: SSL 인증서 검증 여부
    - true: HTTPS 통신 시 SSL 인증서를 검증합니다.
    - false: SSL 인증서 검증을 생략합니다.
    - 일반적인 환경에서는 true 사용을 권장하지만, 기관 내부망 등에서 자체 인증서로 인해 SSL 오류가 발생하는 경우 false로 설정할 수 있습니다.
    - 기본값: false
- `request_interval`: API 요청 간 대기시간(초)
    - 연속으로 VWorld API를 호출할 때 각 요청 사이에 대기할 시간을 지정합니다.
    - 예를 들어 0.05는 요청마다 약 0.05초씩 대기한다는 의미입니다.
    - 값을 너무 작게 설정하면 API 서버에 짧은 시간 동안 많은 요청이 집중될 수 있습니다.
    - 기본값: 0.05
- `request_timeout`: API 요청 제한시간(초)
    - VWorld API에 요청한 뒤 응답을 기다리는 최대 시간을 지정합니다.
    - 지정한 시간 안에 응답이 오지 않으면 해당 요청을 오류로 처리하고 재시도를 수행할 수 있습니다.
    - 기본값: 15
- `max_retry`: API 요청 최대 재시도 횟수
    - 네트워크 오류나 일시적인 통신 장애가 발생했을 때 같은 요청을 다시 시도하는 최대 횟수입니다.
    - 예를 들어 3으로 설정하면 최대 3회까지 요청을 시도합니다.
    - 기본값: 3
- `save_every`: 자동 중간저장 간격(건)
    - 지정한 개수의 데이터 처리가 완료될 때마다 결과 파일을 자동으로 저장합니다.
    - 예를 들어 100으로 설정하면 100건, 200건, 300건 처리 시점마다 중간저장합니다.
    - 전체 데이터가 설정값보다 적은 경우에는 작업 완료 시 저장합니다.
    - 기본값: 100
- `validation_distance_m`: 도로명주소·지번주소 검증 허용거리(m)
    - 도로명주소와 지번주소가 모두 있는 경우 두 주소를 각각 좌표로 변환한 뒤 두 좌표 간 거리를 비교합니다.
    - 두 좌표의 거리가 설정값 이내이면 정상적인 범위로 판단합니다.
    - 예를 들어 1000은 두 좌표가 1km 이내이면 검증 허용 범위로 보는 설정입니다.
    - 대학교, 연구단지, 공장, 대형 공공시설처럼 부지가 넓은 장소를 고려해 기본값은 1,000m로 설정되어 있습니다.
    - 기본값: 1000
- `default_sido`: 기본 시도명
    - 입력 파일의 주소에 시도 정보가 없을 때 주소 앞에 자동으로 보완할 기본 시도명을 입력합니다.
    - 입력 파일에 시도, 시도명 등 시도 관련 컬럼이 있고 해당 행에 값이 존재하면 입력 파일의 값을 우선 사용합니다.
    - 예: "대전광역시"
    - 전국 단위 데이터처럼 하나의 기본 지역을 지정하기 어려운 경우 빈 문자열 ""로 두면 됩니다.
    - 기본값: ""
- `default_sigungu`: 기본 시군구명
    - 입력 파일의 주소에 시군구 정보가 없을 때 주소 앞에 자동으로 보완할 기본 시군구명을 입력합니다.
    - 입력 파일에 시군구, 시군구명 등 시군구 관련 컬럼이 있고 해당 행에 값이 존재하면 입력 파일의 값을 우선 사용합니다.
    - 예: "유성구"
    - 여러 시군구가 혼합된 데이터라면 빈 문자열 ""로 두면 됩니다.
    - 기본값: ""
